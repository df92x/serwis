## Siatka — czytelny YouTube na tablecie

Ścieżka: [`/yt/`](./yt/)

Nakładka webowa na problem ogromnych, mało czytelnych miniaturek w aplikacji YouTube na tablecie (układ telefonu rozciągnięty na cały ekran).

- Wielokolumnowa siatka miniaturek (PWA)
- Userscript CSS dla `youtube.com` / `m.youtube.com`
- Odtwarzanie przez oficjalny embed YouTube (konto Premium w przeglądarce)
